# Archive

This folder holds older versions of templates, facts blocks or rules
from the IT Help Desk Prompt Library.

---

## Current Status

**Empty.** All files in this library start at **v1**. No version has
been superseded yet, so there is nothing archived at this time.

---

## Purpose

The `_archive/` folder keeps the **history** of the library. When a file
is updated, the previous version is moved here instead of being deleted.
This preserves what was tested and approved before, and lets a reviewer
compare versions if a problem appears later.

---

## When to Use This Folder

| Event | What moves here |
|---|---|
| A template is updated from v1 to v2 | The v1 template file |
| The facts block is updated (v1 → v2) | The old facts block file |
| A rule is changed (v1 → v2) | The previous rules file |
| A template is retired | The final version of that template |

---

## Naming Rule

Archived files keep their **original name**, so they stay traceable:

    IT-Reply-Ticket-v1_2026_10_15.md
    IT-Facts-v1_2026_10_15.md
    IT-Rules-v1_2026_10_15.md

The date in the file name tells you when that version was created.

---

## Rule

**Never delete a version.** Move it here, so the library keeps a clear
history of what was tested, approved and used.
